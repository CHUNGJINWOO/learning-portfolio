# 신규 자료 대기소 (Inbox)

본 디렉터리는 새로 학습한 원시 자료, 실습 코드, 메모 등이 포트폴리오에 정식 편입되기 전 거쳐가는 **임시 검토 및 분석 대기 공간**입니다.

---

## 📌 목적

- 새로 습득한 지식을 즉시 아무 곳에나 작성하여 저장소 구조가 오염되는 것을 방지합니다.
- 기존 학습 자료와의 중복 및 연관성을 먼저 분석한 뒤, 가장 알맞은 위치(`notes/`, `exercises/`, `src/`)로 안전하게 정제·이관하는 완충 지대 역할을 합니다.

---

## 📥 넣을 자료 (Included)

1. **학교 수업 후 작성한 원시 실습 코드**:
   - 당일 수업이나 실습에서 작성한 파이썬 스크립트, 아두이노 코드, 메모 등.
2. **트러블슈팅 단서 및 에러 로그**:
   - 실습 중 발생한 터미널 에러 출력 및 해결을 위해 시도했던 메모.
3. **개인 학습 요약 초안**:
   - 공식 문서를 읽으며 메모해 둔 개념 요약 스케치.

---

## 🚫 넣지 않을 자료 (Excluded)

1. **대용량 데이터 파일**:
   - 기가바이트급 데이터셋, 대용량 비디오/이미지 덤프 (저장소 비대화 방지).
2. **보안 민감 정보**:
   - API 키, 서버 비밀번호, SSH 비공개 키 등.
3. **이미 정식 등록된 중복 파일**:
   - `src/`나 `docs/`에 이미 존재하는 완성본 코드.

---

## ⚙️ AI를 이용한 처리 절차 (10단계 안전 원칙)

> [!IMPORTANT]
> **처리 전 원본 불변 원칙 (Non-Destructive Principle)**:
> 사용자가 변경 계획을 명시적으로 승인하기 전까지, AI 에이전트는 `inbox/`에 들어온 원본 파일을 임의로 수정하거나 삭제하지 않습니다.

1. **[투입]**: 사용자가 새 자료를 본 `inbox/` 폴더에 넣습니다.
2. **[분석]**: 에이전트가 파일의 내용, 언어, 주제, 메타데이터를 분석합니다.
3. **[대조]**: 기존 포트폴리오(`docs/`, `src/`, `notes/`)와의 중복 여부를 점검합니다.
4. **[제안]**: 어디로(`notes/`, `exercises/`, `src/`), 어떤 구조로 정제하여 반영할지 계획서를 제출합니다.
5. **[승인 및 반영]**: 사용자가 승인하면 해당 위치로 정제하여 반영하고, `inbox/`를 정리합니다.
