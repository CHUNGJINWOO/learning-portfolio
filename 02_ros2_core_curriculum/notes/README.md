# 개념 및 이론 학습 노트 (Knowledge Notes)

본 디렉터리는 학교 강의, 개인 학습, 공식 문서에서 배운 핵심 개념과 동작 원리를 **학습자가 자신의 언어로 직접 재구성하여 정리한 심층 학습 노트 공간**입니다.

---

## 📌 목적

- 단순한 강의 요약이나 외부 텍스트 복제를 지양하고, 개념의 본질과 원리를 깊이 있게 이해하도록 돕습니다.
- 시간이 지나 다시 읽었을 때도 동작 원리와 설계 이유를 즉시 복기할 수 있도록 체계적으로 정리합니다.
- 향후 Python, C/C++, 임베디드, 로보틱스, AI 등 다양한 분야의 이론적 기반을 축적합니다.

---

## 📥 넣을 자료 (Included)

1. **원리 및 설계 이유 분석**:
   - "왜 이 방식을 사용하는가?", "어떤 대안이 있는가?"에 대한 개념 분석 노트.
2. **아키텍처 및 통신 흐름 다이어그램**:
   - 시스템 블록도, 상태 전이도(State Diagram), 시퀀스 다이어그램(Mermaid).
3. **핵심 문법 및 언어적 특성 비교**:
   - Python 객체지향/비동기, C/C++ 메모리 모델 및 포인터 연산 등.
4. **트러블슈팅 일지 (Troubleshooting Log)**:
   - 발생한 오류 메시지, 원인 분석, 해결 과정, 방어 기법 기록.

2. **외부 튜토리얼의 무단 복사본**:

3. **미검증된 임시 코드 스니펫**:
   - 실행 가능하고 검증된 패키지 코드는 `src/`에서 다루며, 본 디렉터리에는 개념 설명을 위한 최소 스니펫만 포함합니다.

---

## ⚙️ AI를 이용한 처리 절차

1. 사용자가 `inbox/`에 원시 필기나 학습 자료를 투입하면, 에이전트가 이를 분석합니다.
2. 기존 `docs/` 및 `notes/`와의 중복 여부를 대조하고, 선행/후속 관계를 파악합니다.
3. 학습자가 이해한 내용을 바탕으로 적절한 주제별 하위 디렉터리(예: `python/`, `c_cpp/`, `ros2/`, `robotics/`, `infrastructure/`)에 배치할 것을 제안합니다.
4. **사용자의 명시적 승인을 받은 뒤에만** 정식 마크다운 노트로 정제하여 저장합니다.
