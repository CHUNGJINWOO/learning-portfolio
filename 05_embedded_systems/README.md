## 권장 학습·복습 순서

LED → FND → DIP 스위치 → 택트 스위치 → 택트 스위치 풀다운 → PIR → 포텐셔미터 → 조이스틱 순서로 출력, 디지털 입력, 아날로그 입력을 연결해 볼 수 있습니다. 이는 제안 순서이며 개인의 학습 완료를 뜻하지 않습니다.

## 공통 실행 환경

각 프로젝트에는 `.ino`, `diagram.json`, `wokwi.toml`이 있습니다. 회로는 모두 `wokwi-arduino-mega`를 지정합니다. `wokwi.toml`은 해당 프로젝트의 `build/<스케치명>.ino.hex`와 `.ino.elf`를 참조하지만 현재 그 파일들은 원본 프로젝트에 없습니다. Wokwi VS Code 실행에는 해당 설정에 맞는 펌웨어와 사용 가능한 확장·라이선스가 필요합니다.

8개 컴파일은 원본의 내용을 보존한 ASCII 이름 임시 스케치로 수행했습니다. 따라서 그 산출물의 영문 파일명은 원본 `wokwi.toml`의 한글 파일명과 다릅니다. 임시 프로젝트를 이용해 실제 산출물과 설정 경로를 맞추어야 하며, 실행 성공은 별도 확인해야 합니다. 원본을 덮어쓰지 마세요.

## 학습 경험과 기술 검증 상태

- 사용자는 과거 Wokwi·VS Code 실습 경험이 있다고 밝혔습니다. 각 프로젝트의 직접 구현, 이해도와 학습 완료는 사용자 확인이 필요합니다.
- Arduino CLI 1.5.1, AVR 코어 1.8.8, `arduino:avr:mega:cpu=atmega2560`을 사용해 8개 ASCII 이름 임시 복사본의 컴파일이 성공했습니다. 코드 원본과 복사본 해시를 비교했습니다. 컴파일은 회로 동작 검증이 아닙니다.
- 이번 문서 작성에서 Wokwi 시뮬레이션을 재실행하지 않았고 실제 하드웨어 동작도 미검증입니다.
- DIP 활성 코드는 입력을 출력하며 모드 분기는 없습니다. FND 회로는 공통 음극입니다. PIR은 폴링하고 조이스틱에는 데드존 처리가 없습니다. 이름이 풀다운인 택트 프로젝트의 현재 배선은 외부 풀업입니다.
- 각 `.ino`의 주석 처리된 과거 예제와 현재 활성 코드를 구분해 읽으세요.
