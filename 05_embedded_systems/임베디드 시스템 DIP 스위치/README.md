# DIP 스위치

## 1. 실습 개요

여덟 스위치의 디지털 상태를 순서대로 읽어 시리얼로 표시합니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20DIP%20%EC%8A%A4%EC%9C%84%EC%B9%98.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

디지털 입력은 HIGH 또는 LOW 두 상태로 읽습니다. `INPUT_PULLUP`은 내부 저항을 통해 열린 입력을 HIGH로 유지하며, 스위치를 닫아 GND에 연결하면 LOW가 됩니다. `digitalRead()`는 그때의 상태를 읽는 폴링 방식입니다.

## 3. 회로 구성과 핀 연결

Mega의 9, 8, 7, 6, 5, 4, 3, 2번 핀이 각각 스위치 1~8의 입력에 연결됩니다. 각 스위치의 반대편은 GND에 연결됩니다. 브레드보드는 배선과 전원 레일을 연결합니다.

## 4. 활성 코드 분석 및 실행 흐름

`DIP[]`에 핀 순서가 저장됩니다. `setup()`은 8개 입력에 `INPUT_PULLUP`을 설정하고 시리얼을 115200 baud로 시작합니다. 내장 LED도 출력으로 설정하지만 활성 `loop()`에서 제어하지 않습니다. `loop()`는 8개 값을 읽고 순서대로 출력한 뒤 500ms 기다립니다. 조건에 따른 모드 분기는 없습니다.

## 5. 복습 질문·답변과 이유

**Q. 스위치를 닫으면 왜 LOW인가요?** A. 입력이 GND에 연결되기 때문입니다. 열린 상태는 내부 풀업으로 HIGH가 됩니다.

**Q. 출력의 첫 자리는 어느 입력인가요?** A. `DIP[0]`, 즉 핀 9와 스위치 1입니다. 출력 순서는 배열을 따릅니다.
