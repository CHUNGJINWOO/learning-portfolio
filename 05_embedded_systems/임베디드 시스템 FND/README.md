# FND

## 1. 실습 개요

공통 음극 7세그먼트의 각 LED를 구동해 숫자·문자 패턴을 순서대로 표시합니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20FND.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

FND는 여러 LED 세그먼트의 조합으로 모양을 표시합니다. 공통 음극에서는 공통 단자를 GND에 두고 해당 세그먼트에 HIGH를 주어 켭니다. 공통 양극은 일반적으로 구동 극성이 반대이지만 이 회로에서 구현한 방식은 아닙니다. 저항은 각 경로의 전류를 제한합니다.

## 3. 회로 구성과 핀 연결

Mega 핀 배열 `12, 11, 5, 8, 7, 9, 10, 6`이 A, B, C, D, E, F, G, DP 세그먼트에 대응하며 각 경로에 330Ω 저항이 있습니다. `diagram.json`의 디스플레이 속성은 공통 음극입니다.

## 4. 활성 코드 분석 및 실행 흐름

`setup()`은 8개 핀을 OUTPUT으로 설정합니다. `num[17][8]`은 0~9, 문자형 패턴과 소수점의 점등 값을 담습니다. `loop()`는 17개 행을 순서대로 선택하고 `displayFND()`가 각 핀에 해당 값을 기록한 뒤 1초 기다립니다.

## 5. 복습 질문·답변과 이유

**Q. 왜 8개 출력이 필요한가요?** A. A~G의 7개 세그먼트와 소수점 DP를 각각 제어하기 때문입니다.

**Q. 공통 양극도 이 회로에서 검증했나요?** A. 아닙니다. 현재 회로 설정은 공통 음극이며 양극은 비교 개념입니다.

## 7. 학습 경험 및 기술 검증 상태

- 사용자는 과거 Wokwi와 VS Code 실습 경험이 있다고 밝혔습니다. 이 프로젝트의 학습 완료·직접 구현·이해도는 사용자 확인이 필요합니다.
- Arduino CLI 1.5.1과 AVR 코어 1.8.8로 Mega 2560 대상 ASCII 이름 임시 복사본의 컴파일이 성공했습니다. 원본 내용과 복사본 해시는 일치했습니다. 로컬 기록: `/tmp/learning-portfolio-arduino-3b5c/run-3b5d/logs/fnd_display/result.json` (임시 경로로, 다른 환경에서는 제공되지 않을 수 있음).
- 이번 문서 작성에서 Wokwi 시뮬레이션을 재실행하지 않았습니다. 컴파일 성공은 회로 동작 성공을 뜻하지 않습니다.
- 실제 하드웨어 동작은 미검증입니다.
