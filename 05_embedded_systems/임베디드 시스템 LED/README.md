# LED

## 1. 실습 개요

8개 LED에 대칭으로 움직이는 출력 패턴을 만드는 활성 예제를 살펴봅니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20LED.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

`pinMode(..., OUTPUT)`은 핀을 출력으로 설정하고 `digitalWrite()`는 HIGH 또는 LOW를 출력합니다. LED는 극성이 있고, 직렬 저항은 전류를 제한합니다. 배열과 인덱스를 이용하면 반복 동작을 간결하게 표현할 수 있습니다.

## 3. 회로 구성과 핀 연결

Mega 핀 12~5가 LED 8개에 각각 연결되며 각 LED 경로에는 330Ω 저항이 있습니다. LED 반대쪽은 GND 레일에 연결됩니다.

## 4. 활성 코드 분석 및 실행 흐름

`LED[]`는 핀 12부터 5까지의 순서를 보관합니다. `setup()`은 각 핀을 출력으로 설정합니다. `loop()`는 이전 위치의 대칭 LED를 끄고 현재 위치의 대칭 LED를 켠 뒤 500ms 지연합니다. 짝수 LED 수에서 중앙의 중복 단계를 `continue`로 건너뜁니다. 파일 앞부분의 다른 LED 예제는 주석 상태입니다.

## 5. 복습 질문·답변과 이유

**Q. LED마다 저항이 필요한 이유는 무엇인가요?** A. 각 경로의 전류를 제한하기 위해서입니다.

**Q. `delay()` 중에는 다음 반복이 진행되나요?** A. 아니요. 그 시간 동안 현재 코드의 실행 흐름이 기다립니다.

## 7. 학습 경험 및 기술 검증 상태

- 사용자는 과거 Wokwi와 VS Code 실습 경험이 있다고 밝혔습니다. 이 프로젝트의 학습 완료·직접 구현·이해도는 사용자 확인이 필요합니다.
- Arduino CLI 1.5.1과 AVR 코어 1.8.8로 Mega 2560 대상 ASCII 이름 임시 복사본의 컴파일이 성공했습니다. 원본 내용과 복사본 해시는 일치했습니다. 로컬 기록: `/tmp/learning-portfolio-arduino-3b5c/run-3b5d/logs/led_pattern/result.json` (임시 경로로, 다른 환경에서는 제공되지 않을 수 있음).
- 이번 문서 작성에서 Wokwi 시뮬레이션을 재실행하지 않았습니다. 컴파일 성공은 회로 동작 성공을 뜻하지 않습니다.
- 실제 하드웨어 동작은 미검증입니다.
