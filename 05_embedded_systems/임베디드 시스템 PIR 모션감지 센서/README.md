# PIR 모션감지 센서

## 1. 실습 개요

PIR 센서의 디지털 상태를 반복 확인하고 LED와 시리얼에 반영합니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20PIR%20%EB%AA%A8%EC%85%98%EA%B0%90%EC%A7%80%20%EC%84%BC%EC%84%9C.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

PIR 모듈은 감지 상태를 디지털 HIGH/LOW로 출력합니다. 폴링은 프로그램이 주기적으로 입력을 읽는 방식이며, 인터럽트는 별도의 방식입니다. 이 예제에는 인터럽트가 없습니다.

## 3. 회로 구성과 핀 연결

PIR의 VCC와 GND는 각각 Mega 5V와 GND에, OUT은 디지털 핀 2에 연결됩니다. 출력 표시는 보드의 `LED_BUILTIN`과 시리얼을 사용합니다.

## 4. 활성 코드 분석 및 실행 흐름

`setup()`은 핀 2를 INPUT, 내장 LED를 OUTPUT으로 설정하고 115200 baud 시리얼을 시작합니다. `loop()`는 `digitalRead(2)` 결과를 LED에 쓰고 HIGH/LOW에 따른 문구를 출력한 뒤 500ms 지연합니다.

## 5. 복습 질문·답변과 이유

**Q. 센서 변화를 즉시 감지하는 인터럽트 코드가 있나요?** A. 없습니다. `loop()`에서 입력을 읽는 폴링입니다.

**Q. 폴링 간격보다 짧은 변화는 어떻게 될 수 있나요?** A. 읽는 시점 사이에 발생하면 놓칠 수 있습니다.

## 7. 학습 경험 및 기술 검증 상태

- 사용자는 과거 Wokwi와 VS Code 실습 경험이 있다고 밝혔습니다. 이 프로젝트의 학습 완료·직접 구현·이해도는 사용자 확인이 필요합니다.
- Arduino CLI 1.5.1과 AVR 코어 1.8.8로 Mega 2560 대상 ASCII 이름 임시 복사본의 컴파일이 성공했습니다. 원본 내용과 복사본 해시는 일치했습니다. 로컬 기록: `/tmp/learning-portfolio-arduino-3b5c/run-3b5d/logs/pir_sensor/result.json` (임시 경로로, 다른 환경에서는 제공되지 않을 수 있음).
