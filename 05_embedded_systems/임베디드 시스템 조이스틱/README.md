# 조이스틱

## 1. 실습 개요

조이스틱의 두 아날로그 축과 디지털 버튼 값을 함께 읽습니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20%EC%A1%B0%EC%9D%B4%EC%8A%A4%ED%8B%B1.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

`analogRead()`는 입력 전압을 ADC의 정수값으로 바꾸고, `digitalRead()`는 버튼의 HIGH/LOW 상태를 읽습니다. `INPUT_PULLUP` 버튼은 눌렀을 때 GND에 연결되어 LOW가 되는 구성입니다.

## 3. 회로 구성과 핀 연결

조이스틱 HORZ는 Mega A0, VERT는 A1, SEL 버튼은 디지털 핀 2에 연결됩니다. VCC와 GND는 각각 5V와 GND 레일을 사용합니다.

## 4. 활성 코드 분석 및 실행 흐름

`setup()`은 버튼에 `INPUT_PULLUP`을 설정하고 115200 baud 시리얼을 시작합니다. `loop()`는 버튼과 X/Y 값을 읽어 출력한 뒤 10ms 기다립니다. 방향 분류나 데드존 처리는 구현하지 않았습니다.

## 5. 복습 질문·답변과 이유

**Q. 축과 버튼을 읽는 함수가 다른 이유는 무엇인가요?** A. 축은 전압의 연속 변화를 ADC로 읽고, 버튼은 HIGH/LOW로 읽기 때문입니다.

**Q. 중앙값 근처를 무시하는 데드존이 적용되나요?** A. 아닙니다. 현재 코드는 원시 입력값을 출력합니다.
