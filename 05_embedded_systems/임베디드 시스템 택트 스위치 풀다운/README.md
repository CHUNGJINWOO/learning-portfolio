# 택트 스위치 풀다운

## 1. 실습 개요

폴더 이름을 보존한 실습으로, 현재 회로의 버튼 상태를 LED와 시리얼에 표시합니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20%ED%83%9D%ED%8A%B8%20%EC%8A%A4%EC%9C%84%EC%B9%98%20%ED%92%80%EB%8B%A4%EC%9A%B4.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

이름과 달리 현재 회로는 **외부 풀업**입니다. 저항이 입력을 5V로 당기고 버튼은 입력을 GND에 연결합니다. 풀다운은 일반적으로 저항이 입력을 GND로 당기는 다른 구성으로, 이 회로에 구현되어 있지 않습니다.

## 3. 회로 구성과 핀 연결

Mega 핀 2가 1 kΩ 저항을 통해 5V에 연결되고 버튼 반대 접점은 GND에 연결됩니다. 현재 `diagram.json`은 택트 스위치 프로젝트의 회로와 동일합니다. 놓으면 HIGH, 누르면 LOW로 읽힐 것으로 예상되지만 이번 문서 작성에서 시뮬레이션으로 확인하지 않았습니다.

## 4. 활성 코드 분석 및 실행 흐름

`setup()`은 핀 2를 INPUT, 내장 LED를 OUTPUT으로 설정하고 시리얼을 시작합니다. `loop()`는 입력 상태를 읽어 LED에 그대로 쓰고 출력합니다. 활성 코드에는 디바운스나 지연이 없습니다.

## 5. 복습 질문·답변과 이유

**Q. 현재 회로가 풀다운인가요?** A. 아닙니다. 저항이 입력을 5V에 연결하는 외부 풀업입니다.

**Q. 버튼을 누르면 내장 LED는 어떤 상태가 예상되나요?** A. 입력이 LOW가 되고 코드가 그 값을 그대로 쓰므로 꺼질 것으로 예상됩니다. 시뮬레이션 결과는 미확인입니다.

## 7. 학습 경험 및 기술 검증 상태

- 사용자는 과거 Wokwi와 VS Code 실습 경험이 있다고 밝혔습니다. 이 프로젝트의 학습 완료·직접 구현·이해도는 사용자 확인이 필요합니다.
- Arduino CLI 1.5.1과 AVR 코어 1.8.8로 Mega 2560 대상 ASCII 이름 임시 복사본의 컴파일이 성공했습니다. 원본 내용과 복사본 해시는 일치했습니다. 로컬 기록: `/tmp/learning-portfolio-arduino-3b5c/run-3b5d/logs/tact_switch_pulldown/result.json` (임시 경로로, 다른 환경에서는 제공되지 않을 수 있음).
- 이번 문서 작성에서 Wokwi 시뮬레이션을 재실행하지 않았습니다. 컴파일 성공은 회로 동작 성공을 뜻하지 않습니다.
- 실제 하드웨어 동작은 미검증입니다.
