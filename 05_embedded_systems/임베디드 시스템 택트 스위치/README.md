# 택트 스위치

## 1. 실습 개요

버튼 입력의 바운스를 완화하고 안정적인 눌림 전환을 카운트합니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20%ED%83%9D%ED%8A%B8%20%EC%8A%A4%EC%9C%84%EC%B9%98.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

외부 풀업은 저항으로 입력을 HIGH에 유지하고 버튼을 누르면 GND로 연결합니다. 기계식 버튼은 전환 순간 여러 번 흔들릴 수 있는데, 디바운싱은 일정 시간 안정된 상태만 반영하는 방법입니다.

## 3. 회로 구성과 핀 연결

Mega 핀 2는 1 kΩ 저항을 통해 5V에 연결되고, 버튼을 누르면 GND에 연결됩니다. 코드의 `INPUT`은 내부 풀업을 활성화하지 않으므로 이 회로의 외부 저항이 입력을 유지합니다.

## 4. 활성 코드 분석 및 실행 흐름

`setup()`은 초기 입력을 `prev_state`와 `state_stable`에 저장합니다. `loop()`는 변화가 감지되면 `last_bounce_time`을 갱신하고, 10ms를 초과해 상태가 유지되면 안정 상태를 갱신합니다. 안정 상태가 LOW로 바뀔 때만 카운트를 시리얼에 출력합니다. 다른 예제는 주석 처리되어 있습니다.

## 5. 복습 질문·답변과 이유

**Q. 버튼을 누르고 있는 동안 카운트가 계속 늘어나나요?** A. 안정 상태의 전환이 있을 때만 검사하므로 계속 증가하도록 작성되지 않았습니다.

**Q. `INPUT_PULLUP`이 아닌데 왜 입력이 떠 있지 않나요?** A. 회로의 외부 저항이 입력을 5V로 당깁니다.

## 7. 학습 경험 및 기술 검증 상태

- 사용자는 과거 Wokwi와 VS Code 실습 경험이 있다고 밝혔습니다. 이 프로젝트의 학습 완료·직접 구현·이해도는 사용자 확인이 필요합니다.
- Arduino CLI 1.5.1과 AVR 코어 1.8.8로 Mega 2560 대상 ASCII 이름 임시 복사본의 컴파일이 성공했습니다. 원본 내용과 복사본 해시는 일치했습니다. 로컬 기록: `/tmp/learning-portfolio-arduino-3b5c/run-3b5d/logs/tact_switch/result.json` (임시 경로로, 다른 환경에서는 제공되지 않을 수 있음).
- 이번 문서 작성에서 Wokwi 시뮬레이션을 재실행하지 않았습니다. 컴파일 성공은 회로 동작 성공을 뜻하지 않습니다.
- 실제 하드웨어 동작은 미검증입니다.
