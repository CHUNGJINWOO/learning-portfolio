# 포텐셔미터

## 1. 실습 개요

가변저항의 전압을 ADC로 읽고 전압으로 환산해 시리얼에 출력합니다. 원본 구성은 [스케치](%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C%20%EC%8B%9C%EC%8A%A4%ED%85%9C%20%ED%8F%AC%ED%85%90%EC%85%94%EB%AF%B8%ED%84%B0.ino), [회로](diagram.json), [Wokwi 설정](wokwi.toml)입니다.

## 2. 핵심 개념과 동작 원리

포텐셔미터는 전원과 GND 사이의 전압을 나누고 가운데 단자에서 위치에 따른 전압을 제공합니다. ADC는 전압을 정수값으로 변환합니다. 이 코드의 환산은 5V 기준과 10비트 최대값 1023을 가정합니다.

## 3. 회로 구성과 핀 연결

가변저항 VCC는 5V, GND는 GND, 가운데 SIG는 Mega A0에 연결됩니다.

## 4. 활성 코드 분석 및 실행 흐름

`setup()`은 시리얼을 115200 baud로 시작합니다. `loop()`는 `analogRead(A0)` 값을 읽고 `adcVal * 5.0 / 1023.0`을 계산해 출력한 뒤 10ms 기다립니다. 앞부분의 다른 예제는 주석 처리되어 있습니다.

## 5. 복습 질문·답변과 이유

**Q. 식의 1023은 무엇인가요?** A. 코드가 가정한 10비트 ADC의 최대 정수값입니다.

**Q. 출력값은 실제 전압 측정의 정확도를 보장하나요?** A. 아닙니다. 5V 기준과 ADC 조건을 가정한 계산이며 실제 측정은 별도 확인이 필요합니다.

## 7. 학습 경험 및 기술 검증 상태

- 사용자는 과거 Wokwi와 VS Code 실습 경험이 있다고 밝혔습니다. 이 프로젝트의 학습 완료·직접 구현·이해도는 사용자 확인이 필요합니다.
