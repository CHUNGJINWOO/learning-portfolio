# 📥 신규 학습 자료 수집소 (Root Inbox)

본 디렉터리는 새로 학습한 원시 자료, 실습 코드, 에러 로그, 메모 등이 6대 학습 도메인에 정식 편입되기 전 임시로 거쳐가는 **저장소 공통 단일 진입점(Single Entry Point)**입니다.

---

## 📌 목적 및 운영 철학

1. **구조 오염 방지**:
   - 새로 습득한 지식을 검증 없이 기존 도메인에 무분별하게 추가하여 저장소 아키텍처가 오염되는 것을 방지합니다.
2. **사전 분석 및 완충 지대**:
   - 기존 6대 도메인 자료와의 중복 및 연관성을 먼저 분석한 뒤, 가장 알맞은 위치(`01_python_and_oop`, `02_ros2_core_curriculum`, `03_robotics_algorithms`, `04_computer_vision`, `05_embedded_systems`, `06_cloud_and_devops`)로 안전하게 정제·이관하는 완충 공간입니다.
3. **학습 성과의 진실성 보장**:
   - 단순히 `inbox/`에 파일이 들어왔다고 해서 학습 완료나 기술 검증으로 처리하지 않습니다.

---

## ⚠️ 핵심 운영 수칙 (절대 원칙)

> [!IMPORTANT]
> 1. **투입 ≠ Git 커밋 승인**:
>    - `inbox/`에 파일을 넣는 행위는 임시 검토 대기 공간에 배치하는 것일 뿐, Git 커밋 및 공개 승인을 의미하지 않습니다.
>    - 실제 커밋에서는 사용자가 최종 승인한 파일만 명시적으로 스테이징(`git add <file>`)합니다.
> 2. **사용자 승인 전 자동 변경 금지 (Non-Destructive Principle)**:
>    - 사용자가 분류 및 변경 계획을 명시적으로 승인하기 전까지, AI 에이전트는 `inbox/`에 들어온 원본 파일을 임의로 수정, 이동, 삭제하지 않습니다.
> 3. **자동 완료 처리 금지**:
>    - `inbox/` 내 자료는 검토 대기 상태일 뿐이며, AI가 임의로 `PASS` 또는 학습 완료로 표기하지 않습니다.
> 4. **미분류 자료 원형 보존**:
>    - 사용자가 이관을 승인하지 않았거나 추가 확인이 필요한 자료는 `inbox/`에 원형 그대로 안전하게 유지합니다.
> 5. **보안 민감 정보 및 빌드 산출물 커밋 배제**:
>    - API 키, 인증 토큰, 비밀번호, SSH 키 등 민감정보와 빌드 산출물(`build/`, `install/`, `log/`), 대용량 바이너리/rosbag은 공개 커밋에서 철저히 제외합니다 (`.gitignore` 적용).
> 6. **외부 코드 및 강의 자료 출처/재배포 확인**:
>    - 외부 오픈소스 예제나 학교 강의 자료는 출처와 재배포 가능 여부(저작권)를 명확히 확인한 후 정제하여 수용합니다. 학교 공식 강의 슬라이드 원본은 `school/`에 독립 보존합니다.

## 📥 대상 자료 안내

### 포함할 자료 (Included)
- **강의 및 실습 원시 코드**: 당일 실습에서 작성한 Python 스크립트, C++ 코드, 아두이노 스케치, 주피터 노트북 초안
- **트러블슈팅 단서 및 에러 로그**: 실습 중 발생한 터미널 에러 출력 및 해결 시도 메모
- **개인 개념 요약 초안**: 기술 문서나 교재를 읽으며 기록한 마크다운/텍스트 메모
- **실험 데이터 스니펫**: 알고리즘 검증을 위한 소규모 입력 파라미터 및 테스트 출력 결과

### 포함하지 않을 자료 (Excluded)
- **보안 민감 정보**: 서버 접속 키, API 토큰, 사설 환경변수 (`.env`)
- **대용량 파일**: 비디오/이미지 원본 덤프, 빌드 산출물(`build/`, `install/`)
- **학교 원본 아카이브**: 학교 수업 공식 교재 원본은 독립 아카이브인 `school/`에 보존
- **타 프로젝트 고유 산출물**: `Capstone1_limo` 팀 프로젝트 고유 산출물
