# 🤖 ROS2 소스 코드 및 알고리즘 설계

## 1. 디렉토리 개요
- 본 `src` 폴더는 오라클 클라우드 서버(OCI)와 로컬 디바이스(Gram) 간의 분산 통신 및 로봇 제어를 수행하기 위한 ROS2 패키지와 노드 소스 코드를 포함합니다.

## 2. 기술적 선택 이유 (Rationale)
- **분산 통신 아키텍처 (ROS_DOMAIN_ID)**: 동일한 가상 네트워크(Tailscale) 상에서 클라우드의 무거운 연산 노드와 로컬의 UI/입력 제어 노드가 데이터를 원활하게 주고받을 수 있도록 시스템을 분리했습니다.
- **개발 언어**: 알고리즘 검증과 빠른 프로토타이핑을 위해 통신 및 제어 노드는 **Python 3**로 작성하며, 향후 시뮬레이터 내부의 물리 연산 등 실시간 처리가 중요한 부분은 **C++**로 최적화할 계획입니다.

## 3. 의존성 및 시뮬레이션 환경 (Simulation Dependencies)
- 본 저장소의 시뮬레이션 패키지(`limo_ros2`)는 Gazebo와의 연동을 위해 `gazebo_ros_pkgs`를 필요로 합니다.
- `gazebo_ros_pkgs`는 별도 서브모듈 대신 Ubuntu 22.04 LTS 및 ROS 2 Humble 공식 바이너리 패키지로 설치하여 관리합니다:
  ```bash
  sudo apt install ros-humble-gazebo-ros-pkgs
  ```
